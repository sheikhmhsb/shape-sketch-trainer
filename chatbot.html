1

Write the training examples

Each topic (called an intent) has example messages and possible replies. The model only learns to recognize the topic; the reply is then picked from that topic's list. Edit anything you like, or add your own topics, then train.

Format

## name starts a topic.

A plain line is an example message someone might type.

> text is a reply. Add several and the bot picks one at random.

Aim for at least 5 varied examples per topic. More variety means the model handles wording it hasn't seen.

2

Train the model

Computers can't read words, so each message is turned into numbers first. The page builds a vocabulary of every word in your examples, then represents a message as a row of 0s and 1s: a 1 for each vocabulary word the message contains. The network learns which word patterns point to which topic.

// "how do i train it" → [0,1,0,0,1,1,0,…]
function toVector(text) {
  const v = new Array(vocab.length).fill(0);
  for (const w of tokenize(text)) {
    const i = vocab.indexOf(w);
    if (i >= 0) v[i] = 1;
  }
  return v;
}
