Shape Sketch Trainer

A complete machine-learning loop on one page. It creates its own training pictures, trains a small neural network on them while you watch, then uses the trained model to recognize a shape you draw. Nothing is sent to a server.

Make the training data

A model learns from labeled examples. Here we generate 1,800 wobbly, hand-drawn-looking shapes at 28×28 pixels, each tagged as a circle, square or triangle. Sizes, positions, rotations and line widths are random so the model learns the shape itself, not one exact picture.

Each image becomes 784 numbers (28 × 28 pixels, 0 = black, 1 = white).
2

Train the model

The network starts with random weights and guesses at random (about 33% right). On every batch of 32 images it measures how wrong it was, then nudges its weights to be a little less wrong. 15% of the images are held back as a validation set the model never trains on, so you can see whether it really generalizes.

// The model: two convolution blocks, then a classifier
const model = tf.sequential();
model.add(tf.layers.conv2d({inputShape:[28,28,1],
  filters:8, kernelSize:3, activation:'relu'}));
model.add(tf.layers.maxPooling2d({poolSize:2}));
model.add(tf.layers.conv2d({filters:16,
  kernelSize:3, activation:'relu'}));
model.add(tf.layers.maxPooling2d({poolSize:2}));
model.add(tf.layers.flatten());
model.add(tf.layers.dense({units:32, activation:'relu'}));
model.add(tf.layers.dense({units:3, activation:'softmax'}));

model.compile({optimizer: tf.train.adam(0.003),
  loss:'categoricalCrossentropy', metrics:['accuracy']});

// Training: 8 passes over the data
await model.fit(xs, ys, {epochs:8, batchSize:32,
  validationSplit:0.15, shuffle:true});

Use the trained model

Draw a circle, square or triangle. The page shrinks your drawing to 28×28 pixels, the same format as the training data, and calls model.predict(). The output is three probabilities that add up to 100%.
